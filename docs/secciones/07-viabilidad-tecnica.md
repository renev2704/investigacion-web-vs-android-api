# Viabilidad Técnica
## Comparación de Rendimiento Web y Android Consumiendo API REST

La investigación es viable porque todas las herramientas son de acceso libre o gratuito y el hardware ya está disponible. Se utilizará SQL Server 2022 (edición Developer/Express, gratuita para desarrollo), Java 21 con Spring Boot 3.3 (OpenJDK y Apache 2.0), HTML5/CSS3/JavaScript con Chrome 128 para el cliente web, y Kotlin 2.0 con Retrofit 2.11 sobre Android 14 para el cliente móvil. La medición se realizará con scripts propios, Android Profiler y ADB, y el análisis estadístico con Python (pandas/scipy). El hardware requerido es un servidor local Intel Core i5-11400 con 16 GB RAM y Windows 11, junto con un dispositivo Android 14 de 8 GB RAM, ambos ya disponibles. Los datos serán sintéticos y controlados, generados en el propio sistema de inventario con volúmenes de 1.000, 10.000 y 100.000 registros, lo que garantiza repetibilidad y evita el uso de datos sensibles.
Los principales riesgos son: diferencias de red entre clientes (plan alterno: ejecutar ambos en la misma LAN con servidor local), medición no comparable de memoria entre plataformas (plan alterno: reportar métricas por separado usando performance.memory en web y Android Profiler en móvil), y variabilidad por procesos en segundo plano (plan alterno: 10 repeticiones por combinación, reinicio de servicios y cálculo de desviación estándar). Ningún riesgo es alto, por lo que la viabilidad técnica queda aprobada.
