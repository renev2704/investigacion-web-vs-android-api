## Marco Teórico: Eficiencia de Desempeño según ISO/IEC 25010

La calidad del software es un factor determinante en el éxito de cualquier sistema informático. Para evaluar y garantizar un rendimiento óptimo, la norma internacional **ISO/IEC 25010** define un modelo de calidad del producto software compuesto por varias características clave. Dentro de este modelo, la **eficiencia de desempeño** se establece como una de las dimensiones más críticas para medir el comportamiento de una aplicación en relación con los recursos utilizados.

Según la norma ISO/IEC 25010, la eficiencia de desempeño comprende tres subcaracterísticas principales:

1. **Comportamiento en el tiempo (Time Behaviour):**
   Evalúa los tiempos de respuesta, los tiempos de procesamiento y las tasas de rendimiento de un sistema al ejecutar sus funciones bajo condiciones específicas.

2. **Utilización de recursos (Resource Utilization):**
   Analiza las cantidades y los tipos de recursos (como consumo de memoria RAM, uso de CPU y ancho de banda) que el software utiliza para llevar a cabo sus funciones.

3. **Capacidad (Capacity):**
   Define los límites máximos de los parámetros del sistema (como el número de usuarios concurrentes o volumen de transacciones simultáneas), asegurando que la arquitectura responda adecuadamente bajo cargas elevadas.
